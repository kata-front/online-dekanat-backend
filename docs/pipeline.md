# Как работает распознавание

Один запрос → один документ. Тип студент выбирает вручную.

```text
main.py
  → document_loader.load_image: проверить файл, превратить PDF в PNG
  → ocr_service.read_ocr: один локальный запуск Tesseract
      → получить текст и координаты слов из того же результата
  → document_fields.extract_fields: выбрать схему и извлечь поля
      → field_extractor: текстовые метки и нормализация дат
  → marks_service.detect_marks: проверить штрихи подписи
  → marks_service.detect_round_seal: проверить круглый контур печати
  → JSON: document_type + fields
```

## Где что находится

- `main.py` — проверка входа, вызовы сервисов в рабочих потоках, ответ и закрытие файла.
- `document_loader.py` — JPEG/PNG и одностраничный PDF; проверяет размер до рендера.
  Встроенный текст PDF не используется вместо OCR.
- `ocr_service.py` — Tesseract с русской моделью из `models/tessdata`.
  `read_ocr` возвращает словарь `text`/`blocks`; координаты — четыре угла рамки слова.
- `field_extractor.py` — справка об обучении и общие функции чтения полей/дат.
- `document_fields.py` — выбор типа и схемы заявления/справки о практике.
- `marks_service.py` — пиксельные эвристики. В текущем API `detect_marks(..., False)`
  проверяет только подпись; печать проверяется отдельно через `detect_round_seal`.
  Для печати используется расположение возле метки подписи, а не распознанное «М.П.».

`recognition_service` удалён. Второго OCR нет. Нельзя заключать о наличии подписи
только по слову «Подпись» или о печати по «М.П.»; подлинность не проверяется.

## Проверки и границы

Unit-тесты находятся в `tests/`: OCR и его нативный модуль подменены,
PDF/изображения создаются в тестах. Реальное распознавание проверяется отдельно.
На 17 доступных PDF и PNG/JPEG из них поля совпали с эталоном; остальные 13 PDF
из манифеста ещё нужны для полного прогона.

Это этап распознавания и карточки, не весь кейс. Вопрос пока не обрабатывается.
OCR-текст вычисляется, но не возвращается в API. Проверка комплектности,
ответы с источниками и `results.json` будут следующим этапом.
